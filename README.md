# KCL Refund Rights Website

Static public website for the KCL refund consumer-law advocacy project.

## Free publishing with GitHub Pages

1. Create a new public GitHub repository, for example `kcl-refund-rights`.
2. Upload `index.html`, `styles.css`, and `script.js` from this folder.
3. In GitHub, open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save. GitHub will provide a free `https://yourusername.github.io/kcl-refund-rights/` URL.

## Other free publishing options

- Netlify: drag and drop this folder into Netlify.
- Vercel: import the GitHub repository and deploy as a static site.
- Lovable: use the Lovable project link and publish/share from their interface.

## Note

This website is student-led public advocacy explaining the refund legal basis in accessible language.
